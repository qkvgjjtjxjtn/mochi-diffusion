## 🤖 Overview

Mochi Diffusion is a lightweight macOS app using Apple's Core ML framework to run Stable Diffusion on M-series chips with optimised speed and low power usage.

Whether you're a newcomer or a veteran, Mochi Diffusion provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Core ML Native** | Uses Apple Core ML for peak performance on Apple Silicon |
| **SDXL Support** | Generates full 1024x1024 SDXL images on M2 and M3 chips |
| **Gallery View** | Built-in image gallery with prompt and seed metadata stored |
| **Aspect Ratios** | Quick presets for portrait, landscape, and square outputs |
